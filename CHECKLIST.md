# ✅ Junior Front-End Developer Practice Checklist  

## Week 1 – HTML Basics
- [ ] Create a page with a heading (`<h1>`), a paragraph, and an image  
- [ ] Add an ordered list and an unordered list  
- [ ] Add a link to another page you create  
- [ ] **Mini-project:** “About Me” page  

---

## Week 2 – CSS Styling
- [ ] Create an external CSS file and link it properly  
- [ ] Style headings (color, font, size)  
- [ ] Add a background color to a section  
- [ ] Use **classes** and **IDs** for styles  
- [ ] **Mini-project:** Personal blog homepage layout  

---

## Week 3 – Flexbox Layouts
- [ ] Create a navbar with flexbox  
- [ ] Make a 2-column layout (content + sidebar)  
- [ ] Center items vertically and horizontally  
- [ ] **Mini-project:** Portfolio skeleton (navbar, hero, 3 project cards)  

---

## Week 4 – CSS Grid Layouts
- [ ] Build a 3×3 image grid  
- [ ] Create a responsive grid that changes on smaller screens  
- [ ] **Mini-project:** Gallery page with images  

---

## Week 5 – JavaScript Basics
- [ ] Make a button that shows an alert  
- [ ] Create a counter that increases when clicked  
- [ ] Show/hide text with a button  
- [ ] **Mini-project:** To-Do List (add tasks)  

---

## Week 6 – JavaScript Practice
- [ ] Add ability to delete tasks in To-Do List  
- [ ] Practice with `if/else` conditions  
- [ ] Practice with `for` and `while` loops  
- [ ] **Mini-project:** Simple quiz app with 3 questions  

---

## Week 7 – Combine HTML + CSS + JS
- [ ] Navbar + Hero + Projects + Contact form in one page  
- [ ] Style the page with a consistent theme  
- [ ] Make it responsive (works on phone + desktop)  
- [ ] **Mini-project:** Your first Portfolio Website  

---

## Week 8 – Polish & Showcase
- [ ] Refine your portfolio design  
- [ ] Add at least 3 projects (even mini ones)  
- [ ] Test all links and responsiveness  
- [ ] Upload to GitHub Pages / Netlify  
- [ ] Share with friends for feedback
